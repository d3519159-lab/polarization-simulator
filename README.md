# 光的偏振 · 两表仿真

手机和电脑均可使用的简单静态网页。输入两个参考功率，生成两个表格，可复制到 Excel 或下载带 UTF-8 BOM 的 CSV。

在线使用：https://d3519159-lab.github.io/polarization-simulator/

## 使用

1. 第一表填 θ=0° 时的功率。
2. 第二表填一个非消光参考格的功率，默认是波片 γ=90°、检偏器 β=0° 的最大功率。
3. 点“生成两张表”。若“90°”指检偏器，则在可选设置中选择 β=90° 和对应的波片行。

默认按历届完整报告的表格：36个马吕斯点，以及7×12=84个波片点。另兼容含360°的7×13版和7×4简表。手机将宽表转换为逐行卡片，所有数据均可见。

## 模型与来源边界

- 版式参照已有历届报告/处理稿编号 S244、S255、S047、S263，仅使用角度排列与坐标约定，不公开原报告、学生个人信息或实测数值。
- 表1：`P = B + (P0-B) cos²θ`；`cos²θ`从角度重新计算。
- 表2：线偏振入射的 Jones 波片模型，默认相位延迟90°。以参考格校准尺度。完整版使用实验室固定参考、检偏零点为平行；含360°版的零点为消光；简表使用波片光轴参考，可重现对应样本的方向趋势。这是明确的建模约定，不声称能由两点唯一识别真实光路。
- 默认理想数据；可选加性高斯扰动，标准差为各表信号尺度的指定百分比，负值截零。参考点不加噪声，随机种子使同参数结果可重现。
- 输出用于竞赛仿真环节，页面、复制内容、CSV均标注 `SYNTHETIC / 仿真数据`。文件数值不作为实测数据。
- 输入只在浏览器计算；最后一组参数存入本机 localStorage。无第三方脚本、服务器或API密钥。
